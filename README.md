# TCM Kitchen Recipe Book

Plating and ingredient guide for TCM kitchen staff.

## Local editing

```bash
cd recipe-book
python3 serve.py
```

Open http://127.0.0.1:8765/

1. Click **Edit book**
2. Change pills, photos, or remove items
3. Click **Save to this computer** so the files on disk update
4. Push to GitHub to update the live site

Edit mode only works on this computer. The public site is view-only.

## Live site

GitHub Pages publishes the `recipe-book` folder after each push to `main`.
